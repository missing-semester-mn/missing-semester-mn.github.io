Үйлдлийн системээ тохиргооны цэснээс хамаагүй илүү өөрийнхөөрөө тохируулж
болно.

# Гарын товчлуур дахин оноох (Keyboard remapping)

Таны гар дээр бараг хэрэглэдэггүй товчлуурууд байгаа байх. Хэрэггүй товчтой
байхын оронд тэднийг дахин оноож (remap) хэрэгтэй юманд ашиглаж болно.

## Өөр товч болгох

Хамгийн энгийн нь товчийг өөр товч болгох. Жишээ нь Caps Lock-ийг төдийлөн
хэрэглэдэггүй бол илүү хэрэгтэй товч болгож болно. Vim хэрэглэдэг бол Caps
Lock-ийг Escape болгох нь түгээмэл.

macOS дээр энгийн дахин оноолтыг System Preferences-ийн Keyboard тохиргооноос хийж
болно. Илүү нарийн тохиргоонд тусгай програм хэрэгтэй.

## Дурын команд оноох

Товчийг заавал өөр товч болгох албагүй: товч (эсвэл товчны хослол) дарахад
дурын команд ажиллуулдаг болгох хэрэгслүүд бий. Жишээ нь Command+Shift+T дарахад
шинэ терминалын цонх нээгддэг болгож болно.

# Үйлдлийн системийн далд тохиргоо

## macOS

macOS олон хэрэгтэй тохиргоог `defaults` командаар нээж өгдөг. Жишээ нь нуусан
програмуудын Dock дээрх дүрсийг хагас тунгалаг болгох:

```shell
defaults write com.apple.dock showhidden -bool true
```

Боломжтой бүх тохиргооны нэг жагсаалт байдаггүй, гэхдээ Mathias Bynens-ийн
[.macos](https://github.com/mathiasbynens/dotfiles/blob/master/.macos) шиг
тодорхой тохиргоонуудын жагсаалтыг онлайнаас олж болно.

# Цонхны удирдлага

## Хавтанцар цонхны удирдлага (Tiling window management)

[Хавтанцар цонхны удирдлага](https://en.wikipedia.org/wiki/Tiling_window_manager)
бол цонхнуудыг хоорондоо давхцахгүй хүрээнүүдэд хувааж байрлуулдаг арга. Unix
дээр суурилсан үйлдлийн систем хэрэглэдэг бол хавтанцар цонхны менежер суулгаж
болно. Windows, macOS дээр бол үүнтэй төстэй ажилладаг програм суулгаж болно.

## Олон дэлгэцийн удирдлага

Цонхнуудыг дэлгэц хооронд зөөж удирдах товчлолуудыг тохируулж болно.

## Байрлал (Layout)

Цонхнуудаа дэлгэц дээр тогтсон байрлалаар байрлуулдаг бол тэднийг гараараа нэг нэгээр
зөөхийн оронд скрипт бичээд, нэг товчоор байрлуулдаг болгож болно.
