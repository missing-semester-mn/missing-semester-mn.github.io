*Хөгжүүлэлтийн орчин* (development environment) гэдэг нь код бичихдээ өдөр бүр ашигладаг хэрэгслүүдийн багц юм. Голд нь текст засварлах ажил байна; үүн дээр синтаксыг өнгөөр ялгах, төрөл шалгах (type checking), кодыг форматлах, автомат нөхөлт зэрэг зүйлс нэмэгдэнэ. [VS Code][vs-code] зэрэг *IDE* (Integrated Development Environment) эдгээрийг нэг програм дотор багтаадаг. Харин терминал төвтэй ажлын урсгалд [tmux](https://github.com/tmux/tmux), [Vim](https://www.vim.org/), [Zsh](https://www.zsh.org/), мөн тухайн хэлний командын мөрийн хэрэгслүүд болох [Ruff](https://docs.astral.sh/ruff/) (Python-ы линтер/formatter), [Mypy](https://mypy-lang.org/) (Python-ы төрөл шалгагч) зэрэг ордог.

IDE болон терминал төвтэй арга хоёр хоёулаа давуу, сул талтай. GUI-тэй IDE сурахад амар, AI-ийн автомат нөхөлт зэрэг нь ихэвчлэн шууд бэлэн байдаг. Терминал харин хөнгөн, алсын сервер эсвэл GUI байхгүй орчинд бараг цорын ганц сонголт болох үе бий. Аль алиных нь суурийг мэдээд, ядаж нэгийг нь сайн эзэмшээрэй. Одоогоор дуртай IDE байхгүй бол [VS Code][vs-code]-оос эхлэхэд зүгээр.

# Текст засварлах ба Vim {#text-editing-and-vim}

Код бичих үед цагийн ихэнх нь урт текст тасралтгүй бичихэд биш, код дотор хурдан шилжих, хэсэг хэсгээр нь унших, жижиг засваруудыг зөв газарт нь хийхэд зарцуулагддаг. [Vim] яг ийм төрлийн ажилд маш сайн таарсан текст засварлагч.

**Vim-ийн философи.** Vim-ийн гол санаа нь энгийн хэрнээ хүчтэй: интерфейс нь өөрөө текст дотор шилжих, засах зориулалттай програмчлалын хэл шиг ажилладаг. Товч бүр нэг команд, командуудыг хооронд нь хослуулж болно. Vim хулганаас зайлсхийдэг (хэтэрхий удаан), бүр сумтай товчноос ч зайлсхийдэг (гараа хэт их хөдөлгөх хэрэгтэй болдог). Дасчихвал засварлагч бараг бодсон хурдаар тань хөдөлж байгаа мэт мэдрэмж төрдөг.

**Бусад програм дахь Vim-ийн дэмжлэг.** Энэ санааг ашиглахын тулд заавал цэвэр [Vim] дээр амьдрах албагүй. Текст засдаг олон хэрэгсэл өөрөө эсвэл плагинаар "Vim горим" дэмждэг. VS Code-д [VSCodeVim](https://marketplace.visualstudio.com/items?itemName=vscodevim.vim), Zsh-д Vim-ийг дуурайх [суурь дэмжлэг](https://zsh.sourceforge.io/Guide/zshguide04.html), Claude Code-д хүртэл Vim горимын [суурь дэмжлэг](https://code.claude.com/docs/en/interactive-mode#vim-editor-mode) бий. Таны хэрэглэдэг засварлагч эсвэл текст оруулдаг хэрэгсэл Vim горим дэмждэг байх магадлал өндөр.

## Горимтой засварлах

Vim бол *горимтой засварлагч* (modal editor): өөр өөр төрлийн ажилд зориулсан өөр өөр горимтой.

- **Normal**: файл дотор шилжих, засвар хийх
- **Insert**: текст бичих
- **Replace**: текстийг дээрээс нь дарж бичих
- **Visual** (энгийн, мөрөөр, эсвэл блокоор): текст сонгох
- **Command-line**: команд ажиллуулах

Нэг товч өөр өөр горимд өөр утгатай. Жишээ нь `x` товч Insert горимд зүгээр "x" үсэг бичнэ, Normal горимд курсор доорх тэмдэгтийг устгана, Visual горимд сонгосон хэсгийг устгана.

Анхдагч байдлаар Vim одоогийн горимоо зүүн доод буланд харуулдаг. Эхлэх горим нь Normal. Цагийнхаа ихэнхийг Normal, Insert хоёр горимын хооронд өнгөрүүлнэ.

Аль ч горимоос Normal руу буцахдаа `<ESC>` дарна. Normal горимоос Insert руу `i`, Replace руу `R`, Visual руу `v`, Visual Line руу `V`, Visual Block руу `<C-v>` (Ctrl-V, заримдаа `^V` гэж бичдэг), Command-line руу `:` дарж орно.

Vim хэрэглэхэд `<ESC>`-ийг маш их дарна. Тиймээс Caps Lock-ийг Escape болгох ([macOS заавар](https://vim.fandom.com/wiki/Map_caps_lock_to_escape_in_macOS)) эсвэл энгийн товчны хослолоор `<ESC>`-ийг [орлуулах](https://vim.fandom.com/wiki/Avoid_the_escape_key#Mappings) талаар бодоорой.

## Үндэс: текст оруулах

Normal горимоос `i` дараад Insert горим руу орно. Одоо `<ESC>` дарж Normal руу буцах хүртэл Vim бусад л текст засварлагч шиг ажиллана. Дээрх үндсүүдтэй хамт энэ л Vim-ээр файл засаж эхлэхэд хангалттай (гэхдээ бүх юмаа Insert горимоос хийвэл тийм ч үр дүнтэй биш).

## Vim-ийн интерфейс бол програмчлалын хэл

Vim-ийн интерфейс бол програмчлалын хэл. Товчнууд (цээжлэхэд амар нэртэй) нь команд бөгөөд командууд хоорондоо *хослогддог*. Ингэснээр хурдан шилжиж, хурдан засна. Ялангуяа командууд булчингийн санах ойд тань орчихвол гарын байрлалаа сурсны дараа бичих хурд огцом нэмэгддэгтэй адил бүтээмж тань нэмэгдэнэ.

### Шилжилт

Цагийнхаа ихэнхийг Normal горимд өнгөрүүлж, шилжих командуудаар файл дотор явна. Vim-ийн шилжилтүүд текстийн хэсгийг заадаг тул тэднийг "нэр үг" гэж нэрлэдэг.

- Үндсэн шилжилт: `hjkl` (зүүн, доош, дээш, баруун)
- Үгээр: `w` (дараагийн үг), `b` (үгийн эхлэл), `e` (үгийн төгсгөл)
- Мөрөөр: `0` (мөрийн эхлэл), `^` (эхний хоосон биш тэмдэгт), `$` (мөрийн төгсгөл)
- Дэлгэцээр: `H` (дэлгэцийн дээд хэсэг), `M` (дунд), `L` (доод хэсэг)
- Гүйлгэх: `Ctrl-u` (дээш), `Ctrl-d` (доош)
- Файлаар: `gg` (файлын эхлэл), `G` (файлын төгсгөл)
- Мөрийн дугаараар: `:{number}<CR>` эсвэл `{number}G` ({number} дугаартай мөр)
    - `<CR>` нь carriage return буюу Enter товчийг хэлнэ
- Бусад: `%` (хаалт гэх мэт хос тэмдэгтийн нөгөө тал руу)
- Тэмдэгт хайх: `f{character}`, `t{character}`, `F{character}`, `T{character}`
    - одоогийн мөр дээрх {character}-ийг урагш/хойш хайна
    - `,` / `;`-ээр таарцууд хооронд шилжинэ
- Хайлт: `/{regex}`, `n` / `N`-ээр таарцууд хооронд шилжинэ

### Сонголт

Visual горимууд:

- Visual: `v`
- Visual Line: `V`
- Visual Block: `Ctrl-v`

Сонголтоо дээрх шилжих товчнуудаар хийж болно.

### Засвар

Хулганаар хийдэг байсан бүх юмаа одоо гараас, шилжилтүүдтэй хослох засварын командуудаар хийнэ. Яг энд Vim-ийн интерфейс програмчлалын хэл шиг харагдаж эхэлдэг. Vim-ийн засварын командууд нэр үгс дээр үйлдэл хийдэг тул тэднийг "үйл үг" гэж нэрлэдэг.

- `i` Insert горим руу орно
    - гэхдээ текст устгах/өөрчлөхдөө backspace-ээс илүү зүйл хэрэглэмээр байна
- `o` / `O` доор / дээр шинэ мөр нээгээд Insert горим руу орно
- `d{motion}` {motion}-ын хамрах хэсгийг устгана
    - жишээ нь `dw` үг устгана, `d$` мөрийн төгсгөл хүртэл, `d0` мөрийн эхлэл хүртэл устгана
- `c{motion}` {motion}-ын хамрах хэсгийг өөрчилнө
    - жишээ нь `cw` үгийг өөрчилнө
    - `d{motion}` хийгээд `i` дарсантай адил
- `x` тэмдэгт устгана (`dl`-тэй адил)
- `s` тэмдэгт орлуулна (`cl`-тэй адил)
- Visual горим + үйлдэл
    - текст сонгоод `d` дарвал устгана, `c` дарвал өөрчилнө
- `u` буцаах (undo), `<C-r>` дахин хийх (redo)
- `y` хуулах буюу "yank" (`d` гэх мэт зарим команд бас хуулдаг)
- `p` буулгах (paste)
- Сурах юм бас их бий: жишээ нь `~` тэмдэгтийн том/жижиг үсгийг сольдог, `J` мөрүүдийг нийлүүлдэг.

### Тоо

Нэр үг, үйл үгийг тоотой хослуулж хэрэглэвэл тухайн үйлдлийг тэр тоогоор давтана.

- `3w` 3 үг урагшилна
- `5j` 5 мөр доошилно
- `7dw` 7 үг устгана

### Тодотгогч

Тодотгогчоор (modifier) нэр үгийн утгыг өөрчилж болно. Жишээ нь `i` ("inner" буюу "inside", дотор нь), `a` ("around", тойруулаад).

- `ci(` хаалтын доторхыг өөрчилнө
- `ci[` дөрвөлжин хаалтын доторхыг өөрчилнө
- `da'` дан хашилттай тэмдэгт мөрийг хашилтуудтай нь хамт устгана

## Бүгдийг нь нийлүүлбэл

Доор алдаатай [fizz buzz](https://en.wikipedia.org/wiki/Fizz_buzz) хэрэгжүүлэлт байна:

```python
def fizz_buzz(limit):
    for i in range(limit):
        if i % 3 == 0:
            print("fizz", end="")
        if i % 5 == 0:
            print("fizz", end="")
        if i % 3 and i % 5:
            print(i, end="")
        print()

def main():
    fizz_buzz(20)
```

Normal горимоос эхлээд дараах командуудаар алдаануудыг засна:

- Main хэзээ ч дуудагдаагүй
    - `G` дарж файлын төгсгөл рүү очно
    - `o` дарж доор нь шинэ мөр нээнэ
    - `if __name__ == "__main__": main()` гэж бичнэ
        - Засварлагч тань Python-ыг таньдаг бол Insert горимд догол мөрийг автоматаар тавьж магадгүй
    - `<ESC>` дарж Normal горим руу буцна
- Давталт 1-ээс биш 0-ээс эхэлж байна
    - `/` дараад `range`, тэгээд Enter (`<CR>`) дарж "range"-ийг хайна
    - `ww` дарж хоёр үг урагшилна (`2w` гэж ч болно, гэхдээ бага тоонд товчоо давтаж дарах нь их түгээмэл)
    - `i` дарж Insert горим руу ороод `1,` нэмнэ
    - `<ESC>` дарж Normal горим руу буцна
    - `e` дарж дараагийн үгийн төгсгөл рүү очно
    - `a` дарж курсорын араас бичиж эхлээд `+ 1` нэмнэ
    - `<ESC>` дарж Normal горим руу буцна
- 5-д хуваагдах тоон дээр "fizz" хэвлэж байна
    - `:6<CR>` гэж 6-р мөр рүү очно
    - `ci"` гэж хашилтын доторхыг `"buzz"` болгож өөрчилнө
    - `<ESC>` дарж Normal горим руу буцна

## Vim сурах нь

Vim сурах хамгийн сайн арга бол үндсүүдийг (одоо хүртэл үзсэн зүйлс) сураад, хэрэглэдэг бүх програм дээрээ Vim горимыг асаагаад шууд хэрэглэж эхлэх. Хулгана эсвэл сумтай товч руу гар сунгах уруу таталтаас зайлсхий; зарим засварлагчид зөв дадал суулгахын тулд сумтай товчнуудыг бүр идэвхгүй болгож болно.

# Кодын ухаалаг туслах ба хэлний сервер {#code-intelligence-and-language-servers}

IDE-үүд тухайн хэлэнд зориулсан дэмжлэгийг ихэвчлэн [Language Server Protocol](https://microsoft.github.io/language-server-protocol/)-ыг хэрэгжүүлсэн *хэлний сервер* (language server)-тэй холбогддог өргөтгөлөөр дамжуулан өгдөг. Хэлний сервер кодыг тань утга санааных нь түвшинд ойлгодог. Жишээ нь VS Code-ийн [Python өргөтгөл](https://marketplace.visualstudio.com/items?itemName=ms-python.python) [Pylance](https://marketplace.visualstudio.com/items?itemName=ms-python.vscode-pylance)-д, [Go өргөтгөл](https://marketplace.visualstudio.com/items?itemName=golang.go) [gopls](https://go.dev/gopls/)-д тулгуурладаг. Ажилладаг хэлнийхээ өргөтгөл, хэлний серверийг суулгачихвал IDE дээрээ олон боломж нээгдэнэ:

- **Кодын автомат нөхөлт.** Илүү ухаалаг нөхөлт, жишээ нь `object.` гэж бичмэгц тухайн объектын талбар, методуудыг харах.
- **Шууд харагдах баримт бичиг.** Хулганаа дээр нь аваачихад эсвэл автомат нөхөлтийн үеэр баримт бичгийг шууд харах.
- **Тодорхойлолт руу үсрэх.** Хэрэглэгдэж буй газраас нь тодорхойлолт руу нь шууд очих (jump-to-definition), жишээ нь `object.field`-ээс тэр талбарын тодорхойлолт руу.
- **Хэрэглээг олох.** Дээрхийн эсрэг: тухайн талбар эсвэл төрөл хаана хаана хэрэглэгдэж байгааг олох (find references).
- **Import-ын туслах.** Import-уудыг цэгцлэх, хэрэглэгдээгүйг нь устгах, дутуу import-ыг заах.
- **Кодын чанарын хэрэгслүүд.** Эдгээр хэрэгслийг тусад нь ажиллуулж ч болно, гэхдээ хэлний сервер ихэвчлэн өөрөө өгдөг. Форматлагч кодыг тань автоматаар догол мөртэй, нэг хэв маягтай болгоно; төрөл шалгагч, линтерүүд бичиж байх зуур алдааг тань барина. Энэ төрлийн боломжуудыг [Кодын чанар лекц](/2026/code-quality/)-ээр илүү гүнзгий үзнэ.

## Хэлний серверийг тохируулах

Зарим хэлэнд өргөтгөл, хэлний серверийг суулгахад л хангалттай. Харин заримд нь хэлний серверээс бүрэн ашиг хүртэхийн тулд IDE-дээ орчноо зааж өгөх хэрэгтэй. Жишээ нь VS Code-д [Python-ы орчноо](https://code.visualstudio.com/docs/python/environments) зааж өгвөл хэлний сервер таны суулгасан багцуудыг харж чадна. Орчны талаар [Кодыг багцлах ба хүргэх](/2026/shipping-code/) лекцээр дэлгэрэнгүй ярина.

Хэлнээс хамаараад хэлний сервероо тодорхой хэмжээгээр тохируулж болно. Жишээ нь VS Code-ийн Python дэмжлэг дээр Python-ы заавал биш төрлийн тэмдэглэгээ (type annotation) хэрэглэдэггүй төслүүдэд төрлийн статик шалгалтыг унтрааж болно.

# AI-д суурилсан хөгжүүлэлт {#ai-powered-development}

2021 оны дундуур OpenAI-ийн [Codex загвар](https://openai.com/index/openai-codex/) дээр суурилсан [GitHub Copilot][github-copilot] гарч ирснээс хойш [LLM](https://en.wikipedia.org/wiki/Large_language_model)-ийг програм хангамжийн инженерчлэлд өргөн хэрэглэх болсон. Одоогоор гурван үндсэн хэлбэр түгээмэл: автомат нөхөлт, кодын доторх чат, кодын агент.

[github-copilot]: https://github.com/features/copilot/ai-code-editor

## Автомат нөхөлт

AI-ийн автомат нөхөлт IDE-ийн уламжлалт автомат нөхөлттэй ижил хэлбэртэй: бичиж байх зуурт тань курсорын байрлалд үргэлжлэлийг санал болгоно. Заримдаа зүгээр л цаана нь "өөрөө ажиллаад байдаг" боломж байдлаар хэрэглэгддэг. Түүнээс гадна AI-ийн автомат нөхөлтийг ихэвчлэн кодын тайлбараар (comment) [промпт](https://en.wikipedia.org/wiki/Prompt_engineering) өгч чиглүүлдэг.

Жишээ нь эдгээр лекцийн тэмдэглэлийг татаад доторх бүх холбоосыг сугалж авах скрипт бичье. Ингэж эхэлж болно:

```python
import requests

def download_contents(url: str) -> str:
```

Загвар функцийн биеийг гүйцээнэ:

```python
    response = requests.get(url)
    return response.text
```

Тайлбараар нөхөлтийг цааш чиглүүлж болно. Жишээ нь Markdown холбоосуудыг сугалах функц бичиж эхэлсэн ч нэрийг нь ойлгомжтой өгөөгүй бол:

```python
def extract(contents: str) -> list[str]:
```

Загвар иймэрхүү зүйл санал болгож магадгүй:

```python
    lines = contents.splitlines()
    return [line for line in lines if line.strip()]
```

Кодын тайлбараар чиглүүлж болно:

```python
def extract(content: str) -> list[str]:
    # extract all Markdown links from the content
```

Энэ удаад загвар илүү зөв нөхөлт өгнө:

```python
    import re
    pattern = r'\[.*?\]\((.*?)\)'
    return re.findall(pattern, content)
```

Эндээс энэ AI хэрэгслийн нэг сул тал харагдаж байна: зөвхөн курсорын байрлал дээр нөхөлт хийж чаддаг. Энэ тохиолдолд `import re`-г функц дотор биш, модулийн түвшинд (файлын эхэнд) бичих нь илүү зөв байсан.

Дээрх жишээнд тайлбараар нөхөлтийг яаж чиглүүлж болохыг харуулах гэж зориуд муу нэртэй функц хэрэглэсэн; бодит амьдрал дээр `extract_links` шиг ойлгомжтой нэр өгч, docstring бичих хэрэгтэй (тэгвэл загвар дээрхтэй адил нөхөлт санал болгоно).

Туршиж үзэхийн тулд скриптээ ингэж гүйцээж болно:

```python
print(extract(download_contents("https://raw.githubusercontent.com/missing-semester/missing-semester/refs/heads/master/_2026/development-environment.md")))
```

## Кодын доторх чат

Кодын доторх чатаар (inline chat) тодорхой мөр эсвэл блокоо сонгоод загвараас шууд засвар хүснэ. Энэ үед загвар байгаа кодыг өөрчилж чаддаг (зөвхөн курсорын араас код нэмдэг автомат нөхөлтөөс ялгаатай нь).

Дээрх жишээгээ үргэлжлүүлээд, гадны `requests` сан хэрэглэхгүй гэж шийдсэн гэж бодъё. Холбогдох гурван мөрийг сонгоод чатаа нээгээд ингэж хэлж болно:

```
use built-in libraries instead
```

Загвар ийм засвар санал болгоно:

```python
from urllib.request import urlopen

def download_contents(url: str) -> str:
    with urlopen(url) as response:
        return response.read().decode('utf-8')
```

# Өргөтгөл болон IDE-ийн бусад боломжууд {#extensions-and-other-ide-functionality}

IDE бол хүчтэй хэрэгсэл, өргөтгөлүүдээр бүр ч хүчтэй болдог. Бүгдийг нэг лекцэд багтааж чадахгүй тул хамгийн түгээмэл хэдэн өргөтгөлийг дурдъя. Энэ чиглэлээ өөрөө судлаарай; онлайнд алдартай өргөтгөлүүдийн жагсаалт олон бий, жишээ нь Vim-ийн плагинуудад зориулсан [Vim Awesome](https://vimawesome.com/), [суулгалтын тоогоор эрэмбэлсэн VS Code-ийн өргөтгөлүүд](https://marketplace.visualstudio.com/search?target=VSCode&category=All%20categories&sortBy=Installs).

- [Хөгжүүлэлтийн контейнер](https://containers.dev/) (dev container): Түгээмэл IDE-үүдийн дэмждэг dev контейнерүүд (жишээ нь [VS Code-ийн дэмжлэг](https://code.visualstudio.com/docs/devcontainers/containers)) хөгжүүлэлтийн хэрэгслүүдээ контейнер дотор ажиллуулах боломж өгдөг. Хаана ч адилхан ажиллах, бусдаас тусгаарлагдах давуу талтай. Контейнерийн талаар [Кодыг багцлах ба хүргэх](/2026/shipping-code/) лекцээр дэлгэрэнгүй үзнэ.
- Алсаас хөгжүүлэх: SSH-ээр алсын машин дээр хөгжүүлэлт хийх (жишээ нь VS Code-ийн [Remote SSH плагин](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-ssh)-аар). Жишээ нь cloud дээрх хүчтэй GPU-тэй машин дээр код бичиж, ажиллуулахад их эвтэйхэн.
- Хамтран засварлах: Нэг файлыг Google Docs шиг хамтдаа зэрэг засах (жишээ нь VS Code-ийн [Live Share плагин](https://marketplace.visualstudio.com/items?itemName=MS-vsliveshare.vsliveshare)-аар).

# Дасгал ажил

1. Vim горим дэмждэг бүх програм (засварлагч, шелл гэх мэт) дээрээ Vim горимыг асаагаад, дараагийн нэг сар бүх текст засвараа Vim горимоор хийгээрэй. Ямар нэг юм үр ашиггүй санагдах, эсвэл "үүнийг хийх илүү дөхөм арга байгаа байх" гэж бодогдох бүрд Google-ээс хайгаарай, тийм арга байх магадлал өндөр.
1. [VimGolf](https://www.vimgolf.com/)-оос нэг сорилт сонгоод биелүүлж үзээрэй.
1. Ажиллаж байгаа төсөлдөө IDE-ийн өргөтгөл болон хэлний сервер тохируулаарай. Сангийн хамаарлууд руу тодорхойлолт руу үсрэх гэх мэт хүлээгдэж буй бүх боломж зөв ажиллаж байгааг шалгаарай. Ажиллах код байхгүй бол GitHub-аас нэг нээлттэй эхийн төсөл (жишээ нь [энийг](https://github.com/spf13/cobra)) авч болно.
1. IDE-ийн өргөтгөлүүдийн жагсаалтыг гүйлгэж хараад өөрт хэрэгтэй санагдсан нэгийг суулгаарай.
